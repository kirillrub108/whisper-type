# 01. Обзор продукта

## Что это

**WhisperType** — офлайн-программа голосового ввода текста для Windows. Пользователь нажимает
глобальный хоткей, говорит, нажимает снова — распознанный текст вставляется в то поле ввода,
которое сейчас в фокусе, в любом приложении.

Аналоги: Blabby, Wispr Flow. Отличие — полностью локальная работа: нет облака, API-ключей,
аккаунта и подписки.

## Какую проблему решает

Диктовка текста в произвольное приложение (мессенджер, IDE, браузер, терминал) без:

- отправки голоса на чужие серверы,
- необходимости открывать отдельное окно и копировать оттуда результат,
- прав администратора при установке и работе.

## Ключевые свойства (проверяемые по коду)

| Свойство | Где реализовано |
|---|---|
| Полностью офлайн после первой загрузки модели | [stt.py](../whispertype/stt.py) — `local_files_only=offline` |
| Работает без прав администратора | [autostart.py](../whispertype/autostart.py) — только `HKEY_CURRENT_USER`; [installer.iss](../installer.iss) — `PrivilegesRequired=lowest` |
| Один экземпляр | [winutil.py](../whispertype/winutil.py) — именованный mutex |
| Вставка в любое приложение | [inject.py](../whispertype/inject.py) — буфер обмена + `SendInput` |
| Иконка в трее с состояниями | [tray.py](../whispertype/tray.py) |
| Экранный индикатор записи | [overlay.py](../whispertype/overlay.py) |
| История последних фраз с повторной вставкой | [history.py](../whispertype/history.py), [tray.py](../whispertype/tray.py) |

## Целевое железо

Проект писался и замерялся на AMD Ryzen 5 7500F (6 ядер / 12 потоков), 32 ГБ RAM,
Radeon RX 6600. **Инференс только на CPU.** GPU-ускорение (CUDA, ROCm, Vulkan, DirectML)
сознательно не используется — см. «Ограничения» ниже.

## Стек и почему именно он

| Технология | Роль | Почему |
|---|---|---|
| **Python 3.11** | язык | PyInstaller в этой сборке не поддерживает более новые версии — жёстко проверяется в [build.bat](../build.bat) |
| **faster-whisper** (CTranslate2) | распознавание речи | CPU-инференс Whisper в разы быстрее референсной реализации; квантизация `int8_float32` |
| **sounddevice** | захват звука | тонкая обёртка над PortAudio; постоянно открытый поток без переоткрытия устройства |
| **numpy** | обработка аудио | нормализация, поиск точки разреза, конвертация буферов |
| **pystray + Pillow** | иконка и меню в трее | иконки рисуются кодом, без внешних файлов-ассетов |
| **ctypes** (stdlib) | весь WinAPI | см. ниже |
| **PyInstaller** | сборка `.exe` | режим `--onedir` |
| **Inno Setup 6** | инсталлятор | установка в `%LOCALAPPDATA%` без админ-прав |

Полный список версий — [requirements.txt](../requirements.txt), инструменты разработки —
[requirements-dev.txt](../requirements-dev.txt).

### Почему WinAPI через `ctypes`, а не библиотеки хоткеев

Библиотеки `keyboard` и `pynput` намеренно **не используются**:

- они не дают надёжного push-to-talk (не различают физическое удержание и автоповтор так,
  как нужно приложению);
- регулярно попадают в эвристики антивирусов, что для распространяемого `.exe` критично.

Вместо них — прямой низкоуровневый хук `WH_KEYBOARD_LL` через `ctypes`
([hotkey.py](../whispertype/hotkey.py)). Это даёт полный контроль: приложение само решает,
проглотить клавишу или пропустить дальше, и умеет отличать свои же синтезированные события
по флагу `LLKHF_INJECTED`.

Примечательно: **`pywin32` в зависимостях отсутствует** — весь WinAPI-слой написан на голом
`ctypes` плюс stdlib-модули `winreg` и `winsound`. Итого пять внешних пакетов на всё приложение.

### Почему нет GPU

Целевая видеокарта — AMD. Работающие варианты ускорения (`torch` + ROCm, `onnxruntime-gpu`)
добавили бы гигабайты к дистрибутиву ради выигрыша, которого на этой конфигурации может и не
быть. В [whispertype.spec](../whispertype.spec) `torch` явно указан в `excludes`.

## Ограничения

- **Только Windows x64.** Код опирается на WinAPI напрямую; кросс-платформенности нет и не
  планируется.
- **Нет автоматических тестов на WinAPI и аудио.** Покрыта только чистая логика — см.
  [09-conventions.md](09-conventions.md#тесты).
- **Первый запуск требует интернета** для скачивания модели (~1.6 ГБ). Дальше сеть не нужна.

## Проверь себя

1. Почему в проекте нет `pywin32`, хотя приложение целиком построено на WinAPI?
   *(Ответ: весь слой написан на `ctypes`; см. [requirements.txt](../requirements.txt) и
   [inject.py](../whispertype/inject.py).)*
2. Что произойдёт при запуске второй копии программы?
   *(Ответ: [winutil.py](../whispertype/winutil.py) `acquire_single_instance` вернёт `False`,
   и [app.py](../whispertype/app.py) `main()` покажет MessageBox и выйдет с кодом 0.)*
