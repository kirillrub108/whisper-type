# WhisperType

**Голосовой ввод для Windows, который работает в любом приложении**

Нажали **Ctrl+Space**, продиктовали, нажали ещё раз — текст сам появился в том поле, где стоял курсор. Хоть в браузере, хоть в Word, хоть в чате.

- **Полностью офлайн.** Распознавание идёт на вашем компьютере. Никаких API-ключей, аккаунтов и подписок.
- **Бесплатно и без лимитов.** Внутри — Whisper от OpenAI в быстрой реализации faster-whisper.
- **Без прав администратора.** Ни установки, ни изменений в системе: один .exe, который живёт в трее.
- **Быстро.** Около секунды на короткую фразу; длинная диктовка распознаётся прямо во время речи.

Русский и английский из коробки, знаки препинания расставляются автоматически.

## Первый запуск

1. В трее (рядом с часами) появится **серая** иконка — программа запускается.
2. Начнётся загрузка модели распознавания, ~1.6 ГБ. Придёт уведомление, займёт несколько минут. Скачивается один раз, дальше интернет не нужен.
3. Иконка станет **синей** — всё готово.
4. Поставьте курсор в любое поле ввода, нажмите **Ctrl+Space**, скажите что-нибудь, нажмите **Ctrl+Space** ещё раз. Текст появится в поле.

Значок в трее показывает, что происходит:

| Цвет | Что означает |
|---|---|
| Серый | загружается |
| Синий | готов, ждёт нажатия |
| Красный | идёт запись |
| Жёлтый | распознаёт |
| Тёмно-красный с «!» | ошибка — загляните в лог через меню трея |

Пока идёт запись, в правом нижнем углу экрана виден маленький индикатор.

## Как пользоваться

| Действие | Клавиши |
|---|---|
| Начать запись | **Ctrl+Space** |
| Закончить и вставить текст | **Ctrl+Space** ещё раз |
| Отменить, ничего не вставляя | **Esc** |

Правой кнопкой по иконке в трее — меню: последние фразы, выбор микрофона, автозагрузка вместе с Windows, папка с логами, выход.

### Вставить сказанное ещё раз

В меню трея есть пункт **«Последние фразы»** — там лежат десять последних распознанных фраз, свежие сверху. Поставьте курсор туда, куда нужно вставить, откройте меню и щёлкните по фразе — она вставится в то поле, где вы работали до открытия меню.

Удобно, когда одно и то же приходится писать несколько раз: адрес, формулировку, кусок текста. Список переживает перезапуск программы — хранится в `%APPDATA%\WhisperType\history.json`.

Говорить можно сколько угодно (по умолчанию до 2 минут за раз). Длинная диктовка распознаётся кусками прямо во время речи, поэтому ждать после остановки почти не приходится.

## Настройка

Все настройки — в файле `%APPDATA%\WhisperType\config.json`. Он создаётся при первом запуске. Чтобы открыть, вставьте этот путь в адресную строку проводника. **После правок программу нужно перезапустить.**

Сохраняйте файл в кодировке **UTF-8 без BOM**. Блокнот Windows добавляет BOM — лучше редактировать в VS Code или Notepad++.

### Что стоит поменять сразу

**Если вы диктуете не по-русски.** По умолчанию стоит русский. Для английского:

```json
"model": { "language": "en" }
```

Значение `null` включит автоопределение языка, но это вдвое медленнее — лучше указать явно.

**Под свой процессор.** По умолчанию 6 потоков. Поставьте столько, сколько у вас физических ядер:

```json
"model": { "cpu_threads": 8 }
```

**Другой хоткей.** Ctrl+Space перехватывается и перестаёт работать в других программах (например, переключение раскладки). Если мешает:

```json
"hotkey": { "combo": "f9" }
```

Клавиши пишутся через `+`. Доступны: `ctrl/lctrl/rctrl`, `alt/lalt/ralt`, `shift/lshift/rshift`, `win`, `space`, `esc`, `enter`, `tab`, `f1`–`f24`, буквы `a`–`z`, цифры, `numpad0`–`9`, `home/end/pageup/pagedown/insert/delete`, стрелки. Примеры: `"right ctrl"`, `"ctrl+alt+space"`, `"ctrl+shift+d"`.

**Режим «зажать и говорить»** вместо двух нажатий:

```json
"hotkey": { "mode": "push_to_talk" }
```

**Свои термины.** Если диктуете жаргон, имена или английские слова внутри русской речи — перечислите их в подсказке, модель начнёт их узнавать:

```json
"model": {
  "initial_prompt": "Заметка разработчика: Docker, Python, GitHub, pull request, деплой."
}
```

## Если что-то не работает

Первым делом загляните в лог: меню трея → «Открыть папку логов», файл `app.log`. Там видно каждую запись, её длительность и что распозналось.

**Текст не вставляется.** Чаще всего окно в фокусе запущено от администратора — Windows запрещает обычным программам вводить в него текст. Придёт уведомление, а текст останется в буфере обмена: нажмите Ctrl+V вручную. Вторая причина — вы не до конца отпустили клавиши хоткея. Для терминалов и игр, не понимающих Ctrl+V, поставьте `"inject": { "method": "type" }` — тогда текст будет набираться посимвольно.

**Не слышит, ничего не появляется.** Проверьте микрофон в меню трея → «Микрофон». Запись короче 0.3 секунды игнорируется.

**Фраза из истории не вставилась.** Если программе не удалось вернуть фокус окну (например, оно успело закрыться), придёт уведомление, а текст останется в буфере обмена — нажмите Ctrl+V вручную.

**Хоткей не срабатывает.** Если иконка тёмно-красная с «!» — не удалось поставить перехватчик клавиатуры, перезапустите программу. В некоторых играх это блокируют античиты.

**Программа не запускается, вторым окном пишет что уже запущена.** Она уже висит в трее — разверните список скрытых значков стрелкой вверх рядом с часами.

**Ошибается в словах.** Убедитесь, что язык задан правильно (`model.language`). Незнакомые термины и имена перечислите в `model.initial_prompt` — это заметно помогает. Если нужна максимальная точность и не жалко скорости, поставьте полную модель: `"model": { "repo": "Systran/faster-whisper-large-v3" }` — она точнее на русском, но работает в несколько раз дольше.

**Английские слова пишутся кириллицей** («Docker» → «дакр»). Перечислите их в `model.initial_prompt`. Менять язык не нужно: целые английские фразы программа и так пишет латиницей.

**Съедает первый слог или конец фразы.** Понизьте `vad.threshold` до `0.25` и/или увеличьте `vad.speech_pad_ms`.

**Настройки не применяются.** В логе будет строка `не удалось прочитать config.json ... использованы дефолты`. Почти всегда это BOM-метка от Блокнота — пересохраните файл в UTF-8 без BOM. Проверить, что настройки подхватились, можно по строке `загрузка модели ...` в логе: там видны реальные значения.

**Распознавание медленное.** Проверьте, что `model.language` задан явно, `cpu_threads` равен числу ядер, а `adaptive_window` не выключен. Подробнее — ниже.

## Почему это быстро

Whisper устроен так, что всегда прогоняет через энкодер окно длиной 30 секунд — даже если вы сказали одно слово. Поэтому «наивная» реализация тратит одинаковые ~4 секунды и на «привет», и на длинную фразу.

Здесь окно сужается под реальную длину записи (`adaptive_window`), а таймкоды при узком окне отключаются — именно из-за них модель начинала придумывать продолжение за пределами записи и дублировать текст. Замеры на Ryzen 5 7500F, модель turbo, `int8_float32`, по 3 прогона:

| Запись | Полное окно | Как сейчас |
|---|---|---|
| «привет» | 3.8–4.1 с | **1.1 с** |
| фраза 5.5 с | 4.7 с | **1.3 с** |
| фраза с терминами, 8 с | 4.2 с | **1.5 с** |
| диктовка 15 с | 4.5 с | **~0 с** — распозналась во время речи |

Длинная диктовка не ждёт окончания: пока вы говорите, накопленное режется по паузам и распознаётся в фоне (`streaming`), так что после остановки остаётся только короткий хвост. Расплата — процессор занят во время речи, но ждать этого не приходится.

Два ограничения, которые пришлось заложить: окно не сужается ниже 12 секунд (на более узком модель зацикливает одиночное слово, выдавая «Привет.» десять раз подряд) и редкий остаточный самоповтор схлопывается на уровне текста. Побочный эффект — если намеренно продиктовать одно и то же длинное предложение дважды подряд, останется одна копия.

Сужение окна опирается на внутреннюю функцию faster-whisper, поэтому версия библиотеки в `requirements.txt` ограничена сверху.

## Собрать из исходников

Если не хотите скачивать чужой .exe и предпочитаете собрать программу сами — это одна команда, минут пять.

### Шаг 1. Поставьте Python 3.11

Скачайте с [python.org](https://www.python.org/downloads/release/python-3119/) (внизу страницы — «Windows installer (64-bit)») и при установке **обязательно отметьте галочку «Add Python to PATH»**.

Нужна именно версия 3.11: на более новых сборщик .exe пока не работает. Если Python у вас уже стоит другой версии — ничего страшного, они прекрасно уживаются.

> Python из Microsoft Store не подойдёт: из него не собирается .exe. Ставьте с python.org.

### Шаг 2. Скачайте репозиторий

Кнопка **Code → Download ZIP** на странице проекта, затем распакуйте. Либо, если у вас есть git:

```bash
git clone https://github.com/kirillrub108/whisper-type.git
```

### Шаг 3. Соберите программу

Зайдите в папку проекта и запустите `build.bat` — двойным щелчком или командой:

```bash
build.bat
```

Скрипт сам создаст изолированное окружение, поставит зависимости и соберёт всё в один файл. Когда увидите `Готово: dist\WhisperType.exe` — готово.

### Шаг 4. Запустите

Возьмите `dist\WhisperType.exe` и положите куда удобно — хоть на рабочий стол. Запускайте двойным щелчком, устанавливать ничего не надо. Про предупреждение SmartScreen — см. раздел [«Скачать»](#скачать) выше, оно точно такое же.

## Разработка

Запуск из исходников, без сборки .exe:

```bash
py -3.11 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python launcher.py
```

Проверки:

```bash
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest
.venv\Scripts\python -m ruff check whispertype tests
.venv\Scripts\python -m mypy whispertype
```

Тестами покрыта чистая логика: разбор конфига, парсинг хоткеев, постобработка текста и фильтрация галлюцинаций, нарезка аудио, история фраз. WinAPI и звук тестами не покрываются.

Стек: [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (CTranslate2) для распознавания, `sounddevice` для микрофона, `pystray` для трея. Хоткеи и вставка текста — через WinAPI напрямую (`ctypes`), без библиотек вроде `keyboard` и `pynput`: они не дают надёжного перехвата и часто попадают под подозрение антивирусов.
