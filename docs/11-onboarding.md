# 11. Онбординг

План на три дня для разработчика, который видит проект впервые. Ориентирован на человека,
знающего Python, но не обязательно знакомого с WinAPI.

---

## Перед началом

```bash
git clone https://github.com/kirillrub108/whisper-type
cd whisper-type
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt
python -m pytest -q          # должно быть 86 passed
```

Понадобится Windows x64, микрофон и Python **3.11** (не новее — см.
[08-build-release.md](08-build-release.md)).

Первый запуск `python launcher.py` скачает модель ~1.6 ГБ. Запустите заранее, чтобы не ждать
в середине изучения.

## День 1. Понять продукт и общую форму

**Цель дня:** уметь объяснить, что делает программа и как устроен путь от нажатия клавиши до
вставленного текста.

### Читать

1. [README.md](../README.md) — разделы «Как пользоваться» и «Настройка». Взгляд пользователя.
2. [01-overview.md](01-overview.md) — что за продукт, стек, почему такой.
3. [02-architecture.md](02-architecture.md) — модули и, главное, **модель потоков**.
4. [03-runtime-flows.md](03-runtime-flows.md) — сценарии 1–3.

### Смотреть код

| Файл | Что искать |
|---|---|
| [launcher.py](../launcher.py) → [app.py](../whispertype/app.py) `main()` | путь запуска целиком |
| [app.py](../whispertype/app.py) `App.__init__`, `_init` | какие подсистемы создаются и в каком порядке |
| [app.py](../whispertype/app.py) `_handle`, `_start_recording`, `_finish` | state machine |
| [config.py](../whispertype/config.py) | все дефолты — быстро формирует картину возможностей |

### Практика

Запустите программу и **читайте лог** (`%LOCALAPPDATA%\WhisperType\logs\app.log`) во время
работы. Продиктуйте короткую фразу, потом длинную (более 15 секунд). Найдите в логе:

- `загрузка модели ... threads=N авто`
- `промежуточный кусок N с: '...'` — работа стриминга
- `распознано N с аудио за M с` — сколько заняло

Поставьте `log_level: "DEBUG"` в конфиге и повторите.

### Проверка себя к концу дня

- Сколько потоков у работающего приложения и зачем каждый? *(9, см.
  [02-architecture.md](02-architecture.md#модель-потоков))*
- Почему хук не вызывает распознавание напрямую?
- Что произойдёт при нажатии хоткея до загрузки модели?

## День 2. Разобраться в двух сложных слоях

**Цель дня:** понимать, почему WinAPI-код выглядит именно так, и как достигнута скорость.

### Первая половина: WinAPI

Читать [05-winapi.md](05-winapi.md) с открытым кодом:

1. [hotkey.py](../whispertype/hotkey.py) целиком — 161 строка, самый понятный из
   WinAPI-модулей. Обратите внимание на `_ll_proc`: семь шагов, каждый со своей причиной.
2. [inject.py](../whispertype/inject.py) по секциям — не пытайтесь читать подряд. Порядок:
   чистые хелперы → SendInput → буфер обмена → UIPI → фокус.
3. [overlay.py](../whispertype/overlay.py) — по желанию, изолирован от остального.

**Ключевой вопрос дня:** найдите в коде минимум пять комментариев вида «без этого произойдёт
X». Они отмечают места, где очевидное решение не работает.

### Вторая половина: скорость

Читать [06-speed.md](06-speed.md), затем [stt.py](../whispertype/stt.py) целиком (228 строк).

Разберитесь в связке трёх вещей:

```
window_frames_for()  →  encoder_window()  →  without_timestamps
      ширина окна         monkeypatch          условие корректности
```

Затем [textproc.py](../whispertype/textproc.py) — как схлопывается самоповтор.

### Практика

```bash
python -m pytest tests/test_stt_logic.py -v
```

Прочитайте тесты — они формулируют инварианты лучше любого описания. Затем эксперимент:
поставьте `"adaptive_window": false` в конфиге, продиктуйте ту же фразу и сравните время в
логе. Разница должна быть примерно четырёхкратной.

### Проверка себя к концу дня

- Почему сужение окна не работает без `without_timestamps`?
- Что вернёт `window_frames_for(27.0, True)` и почему? *(`None` — 27+4 ≥ 30)*
- Почему автоподбор потоков оставляет два процессора свободными?

## День 3. Внести изменение

**Цель дня:** пройти полный цикл — правка, тест, проверка, сборка.

### Читать

- [09-conventions.md](09-conventions.md) — стиль и рецепты;
- [10-tech-debt.md](10-tech-debt.md) — **обязательно**, особенно «Чего не ломать» в
  предыдущем документе и «Исторические грабли».

### Задача для разминки

Добавьте пункт «Очистить историю» в меню трея. Метод `PhraseHistory.clear()` уже написан и
покрыт тестом — не хватает только пункта меню (см.
[10-tech-debt.md](10-tech-debt.md#мёртвый-код)).

Что затронете: [tray.py](../whispertype/tray.py) `_build_menu`, метод в
[app.py](../whispertype/app.py). Полный рецепт — в
[09-conventions.md](09-conventions.md#добавить-пункт-в-меню-трея).

Проверка: `python -m pytest -q`, `ruff check whispertype tests`, `mypy whispertype`, затем
запуск и клик по новому пункту.

### Задача посложнее

Добавьте параметр конфигурации — например, `history.limit` вместо константы `MAX_PHRASES = 10`.
Затронет `config.py` (dataclass, `_FIELD_TYPES`, `_validate`), `history.py`, `app.py`, тесты и
таблицу в README. Рецепт — [09-conventions.md](09-conventions.md#добавить-параметр-конфигурации).

### Сборка

```bash
build.bat
```

Убедитесь, что получились `dist\WhisperType\WhisperType.exe` и (при установленном Inno Setup)
`dist_installer\WhisperTypeSetup.exe`.

## Финальная самопроверка

Ответьте, не подглядывая. Если больше двух вопросов вызывают затруднение — вернитесь к
соответствующему документу.

1. Пользователь нажал хоткей, сказал «Привет» и нажал снова. Перечислите потоки, задействованные
   от нажатия до вставки текста. *(→ [03](03-runtime-flows.md))*
2. Почему `chunk_seconds` нельзя поставить 29? *(→ [06](06-speed.md))*
3. Текст не вставляется в окно, запущенное от администратора. Что именно происходит и как
   программа это обнаруживает **заранее**? *(→ [05](05-winapi.md#4-uipi-почему-вставка-иногда-невозможна))*
4. Зачем `_persist` перечитывает конфиг с диска? *(→ [07](07-config-data.md))*
5. Почему в проекте не используются библиотеки `keyboard` и `pynput`? *(→ [01](01-overview.md))*
6. Что сломается, если поменять `AppId` в `installer.iss`? *(→ [08](08-build-release.md))*
7. Назовите три вещи, которые нельзя ломать, и почему. *(→ [09](09-conventions.md#чего-не-ломать))*
8. Какая часть кода не покрыта тестами и как в ней ловятся регрессии? *(→ [10](10-tech-debt.md))*
